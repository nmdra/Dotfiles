# Global Behavior Rules

## Big decisions — ask first

- Before making a significant, irreversible, expensive, or ambiguous decision — large refactor or rewrite, deleting data or files, changing provider/model/tools, expanding scope, spending API budget, or anything that would be hard to undo — STOP and ask the user a concise question with concrete options.
- Small, reversible, or routine decisions: proceed without asking.
- When asked, prefer offering 2-3 options with a clear recommendation instead of an open-ended question.
