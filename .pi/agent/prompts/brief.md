Research "$@" and produce a concise brief. For web topics use web_search with 2-4 varied queries; for codebase topics explore the source first.

Format:

## Brief: $@

- **What it is** — 2-3 sentences.
- **Key facts** — bullet points, each with a source citation when from the web.
- **How others use it** — concrete patterns or setups (when relevant).
- **Trade-offs / gotchas** — what to watch out for.
- **Bottom line** — 1-2 sentence recommendation.

Rules:

- Target 150-400 words. Longer only when the topic demands it.
- Cite sources inline (domain or short title) — no footnote dump.
- Distinguish verified facts from speculation ("reported", "appears").
- If the topic is unclear or too broad, ask one clarifying question before researching.
